# Java Setup

**JDK Version:** JDK 25 (LTS)

## "Hello World" Explanation

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

* **`public class HelloWorld`**: Defines the main class. In Java, all code must be inside a class.
* **`public static void main(String[] args)`**: The main method. This is the entry point where the program starts executing.
* **`System.out.println("Hello, World!");`**: Prints the text "Hello, World!" to the console and adds a new line.
